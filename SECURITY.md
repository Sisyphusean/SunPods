# Security

If you find a problem that could put SunPods users at risk, please report it privately through
[GitHub's private reporting](https://github.com/Sisyphusean/SunPods/security/advisories/new)
rather than in a public issue.

Releases are built and signed by GitHub Actions from the `main` branch. Every release APK is signed
with the same key, with SHA-256 certificate fingerprint
`25:B4:96:6B:F0:01:EF:D7:44:D0:2A:D3:45:F6:E8:50:12:EA:4A:D4:DA:49:E0:8F:E5:E4:76:55:3A:62:96:0B`.
An APK signed with any other key isn't from this project.
